# SimpleConfig.txt Specification Guide

This file acts as the Single Source of Truth for both the backend data management and the frontend UI generation.

## ROOT LEVEL PROPERTIES
* ConfigFileName (String) : The name of the .txt file created in the Timberborn PlayerData folder (e.g., "MyModSettings.txt").

---

## SETTING OBJECT PROPERTIES

DEFINITIVE PROPERTY LIST FOR CONFIG SCHEMA

Backend Data Properties:
- Key (String)
- Type (String) - Valid values: "bool", "int", "float", "string"
- DefaultValue (Any/Object)

UI Auto-Commenting Properties:
- Label (String)
- Tooltip (String)

Frontend UI Properties:
- ControlType (String) - Valid values: "Toggle", "Slider", "TextField", "Dropdown", "Color"

Conditional UI Properties (Sliders & Dropdowns):
- MinValue (Number/Float, Optional/Nullable)
- MaxValue (Number/Float, Optional/Nullable)
- Step (Number/Float, Optional/Nullable)
- Options (List of Strings, Optional)

Lifecycle & Scene Properties:
- AvailableInMainMenu (Boolean, Default: true)
- AvailableInGame (Boolean, Default: true)
- AvailableInMapEditor (Boolean, Default: true)
- RequiresRestart (Boolean)
- RequiresReload (Boolean)

Internal State Tracking (Retained from original script):
- IsOrphan (Boolean)
- IsInline (Boolean)
- RawComment (String)


### 1. Backend Data Properties (Required)
These tell the C# backend how to parse the text file and what fallback values to use.
* Key (String)          : The exact identifier written to the .txt file (e.g., "EnableHardMode").
* Type (String)         : The underlying C# variable type. Must be exactly one of: "bool", "int", "float", "string", or "enum".
* DefaultValue (Any)    : The fallback value. Formatting must match the "Type" (e.g., true, 1.5, "Hard").

### 2. Auto-Commenting Properties (Highly Recommended)
These are injected into the .txt file as comments and used as text labels in the UI.
* Label (String)        : The short, human-readable name of the setting (e.g., "Crop Growth Speed").
* Tooltip (String)      : A detailed explanation of what the setting does. Combined with Label for .txt comments.

### 3. Frontend UI Properties (Required)
These tell the dynamic UI builder which visual elements to generate.
* ControlType (String)  : The specific UI toolkit element to draw. Must be exactly one of: "Toggle", "Slider", "TextField", or "Dropdown".

### 4. Conditional UI Properties
These are required only if you are using specific ControlTypes.

If ControlType is "Slider" (Pairs with Type "int" or "float"):
* MinValue (Number)     : The lowest allowed value on the slider. 
* MaxValue (Number)     : The highest allowed value on the slider. 
* Step (Number)         : The increment the slider moves by (e.g., 0.1 for floats, 1 for ints).

If ControlType is "Dropdown" (Pairs with Type "enum" or "string"):
* Options (Array)       : A list of strings representing the valid choices (e.g., ["Easy", "Normal", "Hard"]).
* Note: If your Type is "enum", these strings must exactly match your C# enum names.

### 5. Lifecycle & Scene Properties (Optional)
These handle when a setting can be safely edited and provide player warnings.
* AvailableInMainMenu : bool default true
* AvailableInGame : bool default true
* AvailableInMapEditor: bool default true
* RequiresRestart (Bool): If true, UI displays a warning that a game restart is required.
* RequiresReload (Bool) : If true, UI displays a warning that the player must reload their save.



1. A Dynamic Boolean (Toggle)
For a simple toggle, you map the ControlType , Label , Tooltip , and DefaultValue. If it requires a reload, add the RequiresReload flag.  

Dam.Folktails=false # Label:Folktails Dam | Tooltip:Enables the custom dam variant. | ControlType:Toggle | RequiresReload:true | DefaultValue:false2. A Dynamic Integer (Slider)

For a slider, you include the conditional UI properties: MinValue , MaxValue , and Step.  

LargeIndustrialPile.IronTeeth=500 # Label:IT Industrial Pile | Tooltip:Sets the maximum storage capacity. | ControlType:Slider | MinValue:100 | MaxValue:1000 | Step:50 | DefaultValue:1803. A Dynamic Enum/String (Dropdown)

For a dropdown, you provide the Options array. You can represent the array with brackets.  

MapDisplayState=Single # Label:Map Display Mode | ControlType:Dropdown | Options:[Hidden, Single, Global] | DefaultValue:Hidden

Use this for new format:

Dam.Folktails=false # Inline:true | Label:Folktails Dam | ControlType:Toggle | DefaultValue:false

AdvancedStorageMultiplier=2.5 # Inline:true | Type:float | DefaultValue:1.0 | Label:Global Storage Multiplier | Tooltip:Multiplies the base item capacity of all standard warehouses. | ControlType:Slider | MinValue:1.0 | MaxValue:5.0 | Step:0.5 | RequiresRestart:false | RequiresReload:true | Options:[Low,Medium,High] | AvailableIn:[MainMenu,Game] 


MyModStarter.Config.SetInlineComment("Dam.Folktails", requiresReload: true);
// Results in: # Inline:true | RequiresReload:true

MyModStarter.Config.SetInlineComment(
    key: "LargeIndustrialPile.IronTeeth",
    type: "int",
    defaultValue: 180,
    label: "IT Industrial Pile",
    controlType: "Slider",
    minValue: 50f,
    maxValue: 1000f,
    step: 10f
);
// Results in: # Inline:true | Type:int | DefaultValue:180 | Label:IT Industrial Pile | ControlType:Slider | MinValue:50 | MaxValue:1000 | Step:10

MyModStarter.Config.SetInlineComment(
    key: "MapDisplayState",
    controlType: "Dropdown",
    options: new List<string> { "Hidden", "Single", "Global" },
    availableIn: new List<string> { "MainMenu", "Game" }
);



Key: The unique identifier for the setting (e.g., "UseBagsForDirt", "Dam.Folktails", "GridNormalVerticalOffset").  
Type: The data type of the setting. Valid values found: "bool", "float", "string", "int", "enum".  
DefaultValue: The initial value for the setting.  
Label: The display name shown in the UI.  
Tooltip: The descriptive text shown when hovering over the setting.  
ControlType: The UI element used to display the setting. Valid values found: "Toggle", "Slider", "TextField", "Dropdown".  
MinValue: The minimum allowed value (used mostly for Sliders).  
MaxValue: The maximum allowed value.  
Step: The increment amount for sliders.  
Options: An array of strings used to populate a Dropdown menu.  
RequiresRestart: A boolean indicating if changing the setting requires a full game restart.  
RequiresReload: A boolean indicating if changing the setting requires reloading the current save.
