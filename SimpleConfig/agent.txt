PARSER & HEX PROTECTION UPGRADES (SimpleConfig.cs)
--------------------------------------------------------------------------------
* Objective: Prevent tooltips and strings containing '#' (like hex color codes) 
  from being truncated by the parser, while adding reactive live UI schema updates.
* Backward Compatibility Constraint: Must retain '#' as the structural separator 
  for player-facing config files to protect existing legacy setups.
* Parsing Behavior Fixed:
  - Blueprint Parsing: ParseSchemaFile() entirely skips comment splitting when 
    reading SimpleConfig.txt, protecting all internal text and color strings.
  - Config Parsing: LoadTxt() looks strictly for a " #" (space-hash) sequence to 
    isolate structural metadata blocks from raw '#' color codes inside values.
* Reactive Schema Cache Layer Added:
  - Inside LoadTxt(), an explicit re-parsing block was added to loop over string 
    tokens upon disk-write events caught by FileSystemWatcher.
  - Blueprint entries (SimpleConfig.txt) dynamically refresh their descriptive UI 
    schema definitions (labels, tooltips, limits) without losing core identity.
  - Orphan entries dynamically re-parse whatever text layout strings they currently 
    possess on that exact line.
